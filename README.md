# BPSR_MoudleDropSimulator

本プラグラムはゲーム内のモジュールインベントリ管理、モジュールオプティマイザー(最適化)、および目標達成に必要なドロップ数の確率シミュレーションを行うためのツールです。

## v1.0 更新履歴

* **期待値シュミレーションの再設計**:  計算上の閾値による妥協を完全に排除し、厳密かつ正確な期待値の算出が可能になりました。
* **モジュールオプティマイザー(最適化)の追加**: マルチスレッド並列処理により、膨大な組み合わせの中からわずか1〜2秒で最適解を導出。「詳細モード」を利用することで、物理クラス・魔法クラスなど各プレイヤーに合わせた特化構成の算出も可能です。
* **モジュール取得の実装**: パケットキャプチャを通じたモジュール情報の直接取得を完全Rust化。取得したデータはインベントリ形式で保存でき、アカウントや状況ごとの切り替え・管理に対応しました。
* **GUI化**: 軽量なデスクトップGUIを実装。低負荷で滑らかな操作性を提供します。


---

## 動作環境

* **対応OS**: Windows 10 / 11 (64-bit)
* **必須コンポーネント(パケット自動取得機能を利用する場合のみ)**:
  * **[Npcap](https://npcap.com/)**（Windows用パケットキャプチャドライバ）
    * ※シミュレーションや最適化の計算、手動でのインベントリ管理機能は Npcap なしでも動作しますが、モジュールの取得にはNpcapが必須となります。分からない場合はAIに聞いてください。

## 使い方・起動方法

1. ダウンロードした zip ファイルを任意のフォルダに解凍します。
2. フォルダ内の **`module_simulator.exe`** をダブルクリックして起動します。

## 主な機能

### 1. 期待値シュミレーター/最適化/モジュール取得
* **目標設定**:
  * **必須効果**: 必ずLv.6にしたい通常効果を指定します。
  * **目標効果**: 指定した候補の中から「いずれか◯個以上」を達成する柔軟な目標を設定できます。
* **▶ 最適化実行**:
  * 現在選択中のインベントリにあるモジュールから設定した目標を満たし、かつ合計リンク効果量が最大となるベストな5枠の組み合わせ(最大10パターン)を探索します。
* **▶ シミュレーション実行**:
  * 所持モジュールを考慮した上で成功確率お呼び平均必要ドロップ数(期待値)等を算出します。
* **パケット自動取得**:
  * ゲームを起動した状態で「取得実行」を開始、マップ遷移(TPまたはギルドに戻るなど)を行うことでモジュールの情報を取得。所持済みの全モジュールを自動的に読み込んでインベントリへ保存・反映します。

### 2. 所持モジュール(インベントリ)タブ
* **インベントリ管理**:
  * 複数のインベントリ(キャラクター別・日時別など)の作成・切り替え・名前変更・削除が可能です。
* **強力な絞り込み機能**:
  * モジュールタイプ(攻撃型 / 支援型 / 防御型)
  * レアリティ(金モジュ / 紫モジュ / 青モジュ)
  * ★ お気に入りのみ
  * 効果絞り込み(第1効果 / 第2効果 / 第3効果)
* **お気に入りトグル**:
  * モジュールカード右上の星マーク(★)をクリックすることでお気に入りの登録/解除が可能です。これは期待値や最適化の結果画面からも行えます。

## トラブルシューティング / よくある質問

### Q. パケット取得で「適切なネットワークアダプタが見つかりませんでした」と表示される
1. **Npcap がインストールされているか確認してください**
   * [Npcap 公式サイト (npcap.com)](https://npcap.com/) からインストーラーをダウンロードし、インストールしてください。
   * ※インストール時に「*Install Npcap in WinPcap API-compatible Mode*」にチェックを入れてください。
2. **アダプタを手動で選択してください**
   * 操作画面の「ネットワークアダプタ」プルダウンから、現在インターネット接続に使用しているイーサネット/Wi-Fiアダプタを選択してください。
3. **モジュール以外のデータを利用することはありますか？**
   * モジュール以外のパケットを解析する機能を有しておらず、またアプリケーション外へ情報を発信する機能もありません。

### Q. データはどこに保存されますか？
* インベントリデータは `.exe` と同じフォルダ内の **`modules/`** フォルダ内に `.dat` ファイルとして保存されます。
* 選択中の設定やウィンドウ状態は **`settings.dat`** に自動保存されます。

### Q. アプリケーションのアンインストールについて
* 手動で.exe及び関連する.dat(settings.dat&modules/フォルダー)を削除してください。この他にファイル及びフォルダーが作成されることはありません。
